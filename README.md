I build [**Gaplessly**](https://gaplessly.com), white-label booking software for salons, clinics and restaurants, from Sydney. I worked in venues before I wrote software for them, so the product is shaped by the front desk, not the spreadsheet.

#### What I'm working on

- **[gaplessly/mcp](https://github.com/gaplessly/mcp)**: a booking connector so AI assistants can find free appointment and table times at any Gaplessly venue
- **[gaplessly/cli](https://github.com/gaplessly/cli)**: a command-line client for the Gaplessly booking API
- **Gaplessly itself**: multi-tenant Next.js and Supabase, two products (appointments and hospitality) on one codebase, with a background worker for reminders and notifications
